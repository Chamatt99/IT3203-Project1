What Is Cloud Computing?

Cloud computing provides on-demand access to resources such as servers, storage, and databases over a network. Organizations can scale capacity without purchasing every piece of physical infrastructure themselves.

Common Service Models

Model What it provides Example use
IaaS Virtualized computing infrastructure Hosting virtual machines
PaaS Managed platform for deploying applications Building web apps
SaaS Ready-to-use software over the internet Web-based email

Why Organizations Use the Cloud

  • Adjust capacity as demand changes
  • Access resources from multiple locations
  • Reduce some upfront hardware purchases
  • Use managed services for common infrastructure tasks

Cloud computing also introduces challenges, including cost management, connectivity dependence, and security configuration.
