Seven Key Concepts

These terms provide a foundation for understanding cloud computing and cloud security.

1. Cloud Computing

Access to computing resources delivered on demand over a network.

2. Virtualization

Technology that allows multiple virtual systems to run on physical hardware.

3. Scalability

The ability to increase or decrease resources to meet demand.

4. IaaS

Infrastructure as a Service: cloud-hosted infrastructure such as virtual machines.

5. IAM

Identity and Access Management: controlling who can access which resources.

6. Encryption

Converting readable information into a protected form that requires a key to recover.

7. Shared Responsibility

The division of security tasks between a cloud provider and its customers.
